Como usar o caixa

  1. Cadastre os serviços com os preços praticados pela barbearia.
  2. No resumo, toque no serviço e escolha o pagamento nos botões que se abrem abaixo. O registro só é feito ao escolher o pagamento.
  3. Use Atendimento com mais opções para vários serviços juntos ou descontos.
  4. Registre as despesas pagas para acompanhar o resultado.
  5. Se tocar no serviço errado, use Desfazer último registro. Outros erros podem ser cancelados no histórico, com um motivo.

O resumo considera os valores registrados. Não calcula impostos, saldo bancário, estoque ou contas ainda não pagas.
